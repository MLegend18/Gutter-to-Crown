# Gutter to Crown

A rags-to-riches crime RPG set in Norfolk, Virginia.

- **Play in a browser:** this repo is published with GitHub Pages from `index.html`.
- **Android app:** every time `index.html` (or the app code) changes on `main`, GitHub Actions builds a fresh APK and posts it under **Releases** as `GutterToCrown.apk`.

## Updating the game

Upload the new `index.html` with **Add file → Upload files** and commit. Within a few minutes:
- the web version updates, and
- a new APK appears under Releases (its version number goes up automatically, so phones install it as an update).
